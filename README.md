⏱️ Stopwatch Web Application
A modern, responsive, and feature-rich stopwatch application built purely with vanilla HTML, CSS, and JavaScript. This project showcases a clean user interface with a sleek glassmorphism effect and provides all the standard stopwatch functionalities you'd expect.

✨ Features
▶️ Start/Pause/Resume: Control the timer with intuitive start and pause buttons. The start button intelligently changes to "Resume" after pausing.

🔄 Reset: Easily reset the timer back to zero with a single click.

📝 Lap Times: Record and display multiple lap times on the fly. New laps are added to the top of the list for easy viewing.

🎯 Accurate Timing: The timer updates every 10 milliseconds for precise, reliable measurement.

📱 Responsive Design: The interface is fully responsive and looks fantastic on all devices, from mobile phones to desktops.

💎 Glassmorphism UI: A beautiful "frosted glass" effect on the main container makes the application visually stunning.

🛠️ Technologies Used
HTML5: For the fundamental structure and content of the application.

CSS3: For custom styles, including a sleek custom scrollbar.

Tailwind CSS: A utility-first CSS framework that allowed for rapid and responsive UI development.

JavaScript (ES6): Powering all the core logic, from DOM manipulation to state management.

🧠 Working Knowledge Gained
Building this project was a fantastic exercise in solidifying front-end development fundamentals. Key areas of learning and practice include:

DOM Manipulation: Gained hands-on experience selecting elements, dynamically creating new elements for the lap list, and updating their content based on user actions.

Event Handling: Mastered the use of addEventListener to capture user interactions like button clicks and trigger the corresponding JavaScript functions.

State Management: Learned to manage the application's state through variables (e.g., isRunning, elapsedTime) to logically control the stopwatch's behavior.

JavaScript Timers: Implemented setInterval and clearInterval to create, pause, and reset the core timing loop effectively.

Algorithmic Thinking: Developed a function to accurately format raw milliseconds into a human-readable HH:MM:SS.ms format, including padding numbers for a consistent look.

Responsive CSS: Utilized Tailwind CSS to build a mobile-first, responsive layout, learning how to apply utility classes to create a complex and modern UI efficiently.

📂 Project Structure: Practiced separating concerns by keeping the HTML, CSS, and JavaScript in distinct files, leading to a more organized and maintainable codebase.
