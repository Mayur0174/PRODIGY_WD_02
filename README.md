Stopwatch Web Application
A modern, responsive, and feature-rich stopwatch application built purely with vanilla HTML, CSS, and JavaScript. This project showcases a clean user interface with a glassmorphism effect and provides standard stopwatch functionalities.

Features
Start/Pause/Resume: Control the timer with intuitive start and pause buttons. The start button intelligently changes to "Resume" after pausing.

Reset: Easily reset the timer back to zero.

Lap Times: Record and display multiple lap times. New laps are added to the top of the list for easy viewing.

Accurate Timing: The timer updates every 10 milliseconds for precise measurement.

Responsive Design: The interface is fully responsive and looks great on all devices, from mobile phones to desktops.

Glassmorphism UI: A beautiful "frosted glass" effect on the main container makes the application visually appealing.

Technologies Used
HTML5: For the structure and content of the application.

CSS3: For custom styles, including a custom scrollbar.

Tailwind CSS: A utility-first CSS framework for rapid and responsive UI development.

JavaScript (ES6): For all the core logic, including DOM manipulation, event handling, and state management.

Working Knowledge Gained
Building this project was a great exercise in solidifying front-end development fundamentals. Key areas of learning and practice include:

DOM Manipulation: Gained hands-on experience selecting elements, creating new elements dynamically for the lap list, and updating their content and attributes based on user actions.

Event Handling: Mastered the use of addEventListener to capture user interactions like button clicks and trigger the corresponding JavaScript functions.

State Management: Learned to manage the application's state through variables (e.g., isRunning, elapsedTime, startTime) to control the stopwatch's behavior logically.

JavaScript Timers: Implemented setInterval to create the core timing loop that updates the display and clearInterval to pause and reset it effectively.

Algorithmic Thinking: Developed a function to accurately format milliseconds into a human-readable HH:MM:SS.ms format, including padding numbers to maintain consistent length.

Responsive CSS with a Framework: Utilized Tailwind CSS to build a mobile-first, responsive layout, learning how to apply utility classes to create a complex and modern UI without writing custom CSS from scratch.

Project Structure: Practiced separating concerns by keeping the HTML structure, CSS styling, and JavaScript logic in their own distinct files, leading to a more organized and maintainable codebase.
